# No Unverified Citations

Never cite a paper, dataset, or finding without having verified the specific claim.

## What counts as verified
- You read the actual paper (or its abstract/methodology section) in this session
- The user provided the reference and confirmed the claim
- The claim comes from data in this project that you have read

## What is prohibited
- Citing a paper's methods or findings from general knowledge without verification
- Stating "Paper X uses Y km buffers" or "Paper X finds Z" unless you checked
- Attributing a methodology to a specific author without confirmation
- Inventing plausible-sounding citations to support an argument

## What to do instead
- State the methodological reasoning on its own merits, without false authority
- Say "I have not verified this" if referencing general knowledge
- Use `/lit-review` to actually look up and verify papers before citing
- If the user asks for references, search for them rather than recalling from memory

## Why
Academic credibility requires evidence-backed claims. A fabricated or misattributed citation is worse than no citation — it wastes the user's time verifying it and erodes trust. This applies to all communication: code comments, documentation, verbal explanations.
